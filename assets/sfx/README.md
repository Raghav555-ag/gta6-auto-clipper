# Sound Effects (SFX) Directory

Drop your custom royalty-free sound effects here:
- `whoosh.wav` or `whoosh.mp3`: Subtle camera whoosh for transitions & hook banner
- `pop.wav` or `pop.mp3`: Quick pop for visual callouts & text pop-ins
- `boom.wav` or `boom.mp3`: Cinematic bass drop for punchline/climax impact

If any file is missing, a clean synthetic fallback is automatically generated.
